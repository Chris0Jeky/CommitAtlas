## GitHub profile evidence

The profile repository was published directly to `main` in four reviewed human commits followed by
generated refresh commits, ending at `4651009639e23aad79e106cbdb6ec3bcd2749491`.

- The responsive Atlas remains the primary operating picture.
- Breakdown and Rhythm are visible immediately below it instead of hidden in the expandable section.
- Profile, Streak, Activity, and Languages remain available as optional focused widgets.
- The six-project radar remains visible and is followed by a marker-bounded generated catalog with
  lifecycle, named-workflow CI, language, release metadata, and observed/configured action links.
- GitHub REST's `open_issues_count` includes pull requests, so the final table labels it
  `open issues/PRs` instead of overstating it as issue-only data.
- The narrow live GitHub profile view wrapped focused cards cleanly and rendered the catalog without
  document-level horizontal overflow. The cards, project radar, action destinations, and generated
  truth copy were visually inspected after refresh.
- Consumer tests passed 4/4. Replacement is idempotent and fails closed on missing/reversed/duplicate
  markers, unsupported schema versions, unknown fields, unsafe URLs, and Markdown/table edge cases.
- The final manifest records 11 payload artifacts from one public snapshot; all byte counts and
  SHA-256 digests match. All nine SVGs parse as XML and contain no script, `foreignObject`, event
  handler, external resource, credential, or private-data string.
- Hosted [refresh run 32429850680](https://github.com/Chris0Jeky/Chris0Jeky/actions/runs/32429850680)
  passed generation, bundle validation, catalog update, commit, and push on the first run.

The profile intentionally embeds dated checked-in snapshots rather than request-time live cards. A
failed refresh leaves the last committed good output online.

## Direct HTTP, cache, and security evidence

- Health and all eight deterministic synthetic SVG routes returned 200 from version 8.
- Every exercised SVG returned `image/svg+xml`, its intended public cache policy, a CSP, accessible
  metadata, and no script. The animated Breakdown route also exposed reduced-motion CSS.
- An unknown query parameter returned bounded 400 with `Cache-Control: no-store`.
- Live public availability remains intentionally honest: live Languages returned 200 during final QA,
  live Profile returned 429 at anonymous quota, and live Breakdown returned bounded 502 twice when
  GitHub did not answer before the deadline.
- Project action anchors remain HTML/Markdown-only by design; a README SVG is a single image link and
  cannot reliably expose several independent destinations.

## Review concerns closed in code

The final two review rounds found and closed the only release-blocking insight-suite defect: public
activity percentages were visually associated with a requested contribution window even though the
logged-out GitHub source exposes calendar-year profile percentages. Public Breakdown and Atlas now
say `not window-scoped` in visible and accessible text, while token-backed exact counts remain
window-scoped. Rhythm accessibility also says it is not a GitHub rank.

The separate catalog review found no CRITICAL/HIGH blocker. Its delimiter/ownership/trust-boundary
hardening ideas are tracked in [#50](https://github.com/Chris0Jeky/CommitAtlas/issues/50), not silently
folded into this release slice.
