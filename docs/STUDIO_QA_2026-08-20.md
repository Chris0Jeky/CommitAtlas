## Accessibility limitation

Landmarks, accessible names, labels, legends, the live status region, reduced-motion styling, and a
visible focus treatment were inspected. The browser-control layer did not move focus when asked to
send Tab/Space, even after the documented fallback was tried. Full sequential keyboard traversal is
therefore **not verified** and must be repeated with a real keyboard or a browser driver that can
prove focus movement. Do not convert this limitation into a passing claim.

## Independent review blocker

The fresh review found one HIGH defect in `app/studio/studio-client.tsx`: selected Streak and
Activity cards are always included in copied Markdown. In live-public mode without available
contribution data, the UI truthfully reports the history as unavailable, but the copied URLs use
`demo=false`. Those two shipped endpoints intentionally return `503 token_required`, so the primary
copy action creates broken README images in a normal supported configuration.

This finding came from the required independent local review and remains binding even though GitHub
reports the PR as mergeable.
