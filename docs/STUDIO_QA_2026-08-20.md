## GitHub profile evidence

The profile repository was published directly to `main` in two focused commits, ending at
`5033fb0`:

- The old paused/brittle third-party stats surfaces were removed.
- Taskdeck now has accurate `v0.1.0` release notes, docs, source, and direct Windows download links.
- CommitAtlas renders public profile, language, and six-project lifecycle/CI snapshots from public
  data only. No private contribution data was requested or embedded.
- The selected project set is Taskdeck, CommitAtlas, IdleHarbor, developer-lens, llm-release-gate,
  and MDviewer. Lifecycle is explicitly curated; CI names an actual workflow per repository.
- All three SVGs parse, expose `role="img"`, `aria-label`, one title, and one description, and contain
  no script, animation, external resource, credential, or forbidden XML control.
- On the live GitHub profile, all three SVGs loaded at intrinsic dimensions. At 390 px they render
  as readable full-width cards; at 1440 px they remain aligned and unclipped. The browser console
  was empty.

The profile deliberately embeds dated checked-in snapshots rather than live card URLs. Anonymous
GitHub quota exhaustion intermittently returns 429, so a live embed would make the profile brittle.
Every snapshot links to the Studio for a current preview when quota is available.

## Direct HTTP, cache, and security evidence

- All five synthetic SVG routes returned 200 and accessible bounded SVG.
- SVG responses include strict script/object/frame blocking, `nosniff`, no-referrer, cross-origin
  resource policy, CORS, and stable ETags. Conditional requests returned empty 304 responses.
- Invalid, duplicate, unknown, and traversal-shaped queries returned bounded 400 responses with
  `Cache-Control: no-store`.
- Project action anchors are HTML-only by design; a README SVG is a single image link and cannot
  reliably expose multiple independent action targets.

## Review concerns closed in code

The twelve concerns present when the work resumed were reproduced and causally classified. The
confirmed seams covered unavailable contribution Markdown, stale origins/snapshots, partial star
totals, invented CI, whitespace normalization, workflow delimiter escaping, six-project bounds,
action-host validation, Paper contrast, zero-day bars, and partial-state wording. Those twelve were
answered and resolved before merge. A later review added three threads: the P1 truncated-language
defect was fixed, answered, and resolved at `948c795`; two P2-only findings were answered with parked
classifications and remain unresolved. Current thread state is therefore 13 resolved and two
explicitly parked, not zero unresolved.

## NOT verified

- Full sequential keyboard-only traversal. Landmarks, headings, names, labels, legends, live status,
  focus styling, and reduced motion were inspected, but the browser controller could not reliably
  prove a complete Tab/Space path.
- Token-backed live contributions with a credential positively proved public-only. A private-capable
  token was deliberately not placed in Sites.
- GitHub `v0.1.0`, npm publication, static generator, or Node 24 Action release.

## Tracked nonblocking review work

- Repository-rename redirects can hide optional Docs/Install/Download actions because draft matching
  currently uses the canonical response name.
- Local `127.0.0.1` and `::1` Studio origins do not receive the same preview-only warning as literal
  `localhost`; the production HTTPS origin is unaffected.
- [#48](https://github.com/Chris0Jeky/CommitAtlas/issues/48) records the same-key failed-refresh
  decision for retained preview evidence.
